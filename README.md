#Sudoku game
#Overview
This is a Sudoku game implemented in Python using the Pygame library. The game allows users to play Sudoku puzzles, with features including puzzle generation, user input handling, and a solver using the backtracking algorithm.

#Features
Interactive Sudoku Board: Play Sudoku with a user-friendly interface.
Puzzle Generation: Automatically generate Sudoku puzzles.
Solver: Solve puzzles using the backtracking algorithm.
User Input: Enter numbers and interact with the game using the mouse and keyboard.

#How to play
Click on a cell to select it.
Use the keyboard to enter numbers (1-9).
